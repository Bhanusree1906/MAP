## Description

Cases are created in Salesforce from different channels such as Web, Email, Phone, and other sources.
The Support team wants Cases created through Phone to be treated as more urgent than Cases coming from other channels.
Currently, Case Priority is selected manually, which can result in inconsistent prioritization.
This ticket will automate Case Priority based on the standard Case Origin field.
