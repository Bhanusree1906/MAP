Business Context & Objective

Inside sales representatives at enterprise tiers require an intuitive, low-latency console view to prioritize daily outbound outreach based on real-time AI propensity scores. Currently, reps query disparate report tabs which slows response time during high-velocity inbound qualification windows. This component embeds directly on the Lead list view home and Opportunity launchpad, enabling 1-click bulk qualification and automated dispatch into HubSpot routing channels.

format_list_bulleted

Functional Requirements

  • Responsive Lightning Web Component (leadPriorityConsole) compliant with Lightning Experience Desktop and Mobile Console specifications.
  • Wire service adapter consuming LeadScoringService.cls telemetry with reactive caching keys.
  • Visual urgency badges mapped directly to propensity ranges: High (Red) > 85 Medium (Amber) 50-84 Nurture (Blue) < 50
Workflow Sequence
  1. Display top 20 leads sorted by propensity score descending with live pagination.
  2. Support single-click 'Qualify & Create Opportunity' modal dialog with auto-populated contact fields.
  3. Log audit event to Agent_Audit_Log__c custom object upon state transition for compliance observability.
